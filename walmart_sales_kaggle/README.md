# Walmart Sales Data Analysis

## Project Overview
An analysis of 143 weeks of sales data from 45 Walmart stores to see the individual store performances, impact on sales by different variable on different stores.

## Business Questions
- Which stores generate the highest total revenue?
- How do holiday weeks impact sales performance?
- Is there a relationship between unemployment and weekly sales?

## Tools Used
- **SQL (PostgreSQL)**: Data extraction, aggregation, and analysis.
