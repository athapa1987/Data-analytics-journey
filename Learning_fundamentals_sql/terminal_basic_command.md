**connecting to postgres**
```bash
psql -U postgres
```

**view database list**
```bash
\l
```
**connect to a database**
```bash
\c table name
```
**view table list**
```bash
\dt
```
**View table structure (columns, data types, constraints)**
```bash
\d table name
```
- it display the table information and it is more easier and clear to view than to see in pgadmin

**quit postgres**
```bash
\q
```

**to directly connect to the database**
psql -U postgres -d (the database name)

**Note:** These are the PostgreSQL terminal commands I consider most important for database navigation. Other commands and SQL queries are documented separately.
