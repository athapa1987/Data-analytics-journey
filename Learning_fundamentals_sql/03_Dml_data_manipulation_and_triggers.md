# Data Manipulation Language (DML), Constraints, and Audit Triggers in PostgreSQL

## Cleanup & Fresh Start
Dropping all previous databases, tables, functions, and triggers from the `ashok` schema to build a clean, optimized version from scratch again
```sql
DROP DATABASE ashok WITH (FORCE);
```
I tried to drop the database, but PostgreSQL would not allow it because there were still active connections. I used WITH (FORCE) to terminate eligible connections and drop the database.

**'Note'**: This is only for practice purposes. In a real-world environment, I would not use this command on a production database without proper authorization, backups, and a clear understanding of the consequences, as it permanently deletes the database and its data.

## Creating table employees
```sql
create table employees (

employees_code varchar(50) not null,

```
## creating sequence to generate employees code
```sql
create sequence hr_seq start 1000;
create sequence it_seq start 2000;
create sequence fin_seq start 3000;
create sequence mar_seq start 4000;
create sequence op_seq start 5000;
create sequence oth_seq start 7000;
```

## creating function to assign employee code 
```sql
create or replace function generate_employees_code()
returns trigger as $$
begin
if new.department='HR' then
new.employees_code := nextval ('hr_seq'):: text ||'HR';
elsif new.department='IT' then
new.employees_code := nextval ('it_seq'):: text ||'IT';
elsif new.department='Finance' then
new.employees_code := nextval ('fin_seq'):: text ||'FIN';
elsif new.department='Marketing' then
new.employees_code := nextval ('mar_seq'):: text ||'MAR';
elsif new.department='Operation' then
new.employees_code := nextval ('op_seq'):: text ||'OP';
else
new.employees_code := nextval ('oth_seq') :: text || 'OTH';
end if; 
return new;
end; 
$$ language plpgsql;
```

## executing the function for employee code
```sql
create trigger employee_code_generator
before insert on employees
for each row
execute function generate_employees_code();
```

## Creating new table for salary_history
```sql
create table salary_history (
history_id bigint primary key generated always as identity, 
employees_id bigint not null references employees, 
old_salary dec(10, 2) not null default 0.00, 
current_salary dec(10,2) not null, 
updated_on timestamp not null default current_timestamp, 
updated_by varchar (50) not null default current_user
);
```

## inserting data into salary_history
```sql
insert into salary_history (employees_id, current_salary)
select
employees_id, 
salary as current_salary
from employees;
```

## creating function for auto update of salary in salary_history table
creating function
```sql
CREATE OR REPLACE FUNCTION log_salary_changes ()
RETURNS TRIGGER AS $$
BEGIN 
IF (TG_OP= 'INSERT') THEN
INSERT INTO salary_history (employees_id, old_salary, current_salary)
VALUES (new.employees_id, 0.00, new.salary);
RETURN NEW; 
ELSIF (TG_OP= 'UPDATE') THEN
IF old.salary IS DISTINCT FROM new.salary THEN 
INSERT INTO salary_history (employees_id,old_salary,current_salary)
VALUES (old.employees_id, old.salary, new.salary);
END IF; 
RETURN NEW; 
END IF; 
RETURN NULL;
END;
$$ LANGUAGE plpgsql;
```

executing function 
```sql
CREATE TRIGGER trg_Salary_history_update
AFTER INSERT OR UPDATE ON employees 
FOR EACH ROW
EXECUTE FUNCTION log_salary_changes();
```

## Verifying if the Update trigger is working as intended
```sql
select 
sh. history_id,
e. employees_id,
e. full_name,
sh.old_salary,
sh.current_salary,
e. department
from salary_history sh
join employees e 
on sh.employees_id = e. employees_id
order by e.department, sh.employees_id;
```
It's working.
