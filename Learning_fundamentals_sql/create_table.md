## 2. Table Creation (`CREATE TABLE`)

The script below creates an `employees` table using explicit data types and integrity rules to prevent bad or duplicate data.

### Cleaned SQL Script
```sql
CREATE TABLE employees (
   Employees_id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY (START WITH 1234 INCREMENT BY 104),
    First_name VARCHAR(50),
	Last_name VARCHAR (50),
	Email VARCHAR (150) UNIQUE,
    Department VARCHAR(50),
    Salary DECIMAL(10,2) DEFAULT 30000.00,
    Start_date DATE 
);
```
