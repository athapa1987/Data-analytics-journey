## 2. Table Creation (`CREATE TABLE`)

The script below creates an `employees` table using explicit data types and integrity rules to prevent bad or duplicate data.

### Cleaned SQL Script
```sql
CREATE TABLE employees (
   Employees_id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY (START WITH 1234 INCREMENT BY 104),
    First_name VARCHAR(50),
	Last_name VARCHAR (50),
	Email VARCHAR (150) UNIQUE,
    Department VARCHAR(50),
    Salary DECIMAL(10,2) DEFAULT 30000.00,
    Hire_date DATE 
);
```

## 3. Actually I want to change hire date column to start date, thus use altered table and renamed the column:

```sql
ALTER TABLE employees 
RENAME COLUMN Hire_date TO Start_date;
```
## 4. I wanted to put put default on Start date so that I selected alter and set the data to default as current date 
```sql
ALTER TABLE employees 
ALTER COLUMN Start_date SET DEFAULT CURRENT_DATE;
```

* Putting 'not null' after firstname, last name, email before unique, department could make those data mandatory thus it could be better this way to create table
  
```sql
CREATE TABLE employees (
    employees_id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY (START WITH 1234 INCREMENT BY 104),
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    email VARCHAR(150) NOT NULL UNIQUE,
    department VARCHAR(50),
    salary DECIMAL(10,2) DEFAULT 30000.00,
    start_date DATE NOT NULL DEFAULT CURRENT_DATE
);
